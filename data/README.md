# `data/`

Nothing large in here is committed — see [.gitignore](../.gitignore). Only this
README and `emotions_171.txt` are tracked.

## Contents

| Path | Tracked | What |
|---|---|---|
| `emotions_171.txt` | yes | The 171 emotion words from Anthropic's paper appendix, one per line, alphabetical. Used to validate `config.emotions`. |
| `hf_cache/` | no | Hugging Face datasets + model cache, when `HF_HOME` is unset. |

## The stories

Stories are **not** stored here as files and are **not** generated by this project.
They are loaded on demand through `datasets` from the Hub:

```python
from datasets import load_dataset

stories = load_dataset(
    "ryancodrai/emotion-probes",
    data_files="expression/stories.parquet",
    split="train",
)          # 205,200 rows: emotion, topic, story

neutral = load_dataset(
    "ryancodrai/emotion-probes",
    data_files="expression/neutral_stories.parquet",
    split="train",
)          # 1,200 rows: topic, story
```

`core/dataset.py` wraps these, adds stable example ids, and validates the structure.

Note that the repository's single `default` config concatenates **all four** files
(including `deflection/*`, which we do not use) into one 447,000-row `train` split
with a merged schema. Always pass `data_files` explicitly, as above, rather than
loading the default config.

Source: [`ryancodrai/emotion-probes`](https://huggingface.co/datasets/ryancodrai/emotion-probes),
CC-BY-4.0, by Ryan Codrai, generated with Gemini 3.1 Pro Preview following
Anthropic's methodology. Cached locally under `hf_cache/` (or `$HF_HOME`).

On RunPod, point the cache at a volume so it survives pod restarts and does not fill
the container's root disk:

```bash
export HF_HOME=/workspace/hf_cache
```

## Emotion cache size

`expression/stories.parquet` is ~100 MiB; `expression/neutral_stories.parquet` is
~0.5 MiB. The `deflection/` files (which we never load) account for most of the
dataset's ~1.4 GiB total.
